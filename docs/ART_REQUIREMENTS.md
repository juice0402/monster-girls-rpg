# 絵とエフェクトの要件定義（全キャラ共通）

更新日：2026-11-14 ／ 決めた人：しょーくん（11/14 夜、【monmusu】チャット）
**この要件が、絵とエフェクトについていちばん強い決まり。** 手順は `docs/ART_PIPELINE.md`、制作仕様は `docs/CHARACTER_FX_MASTER_SPEC.md`、ChatGPT に見せる決まりは `art-requests/README.md` と `art-requests/GPT_PROJECT.md`。ちがう所があれば、このファイルに合わせて直す。
このファイルは Claude 用（くわしくてよい）。ChatGPT に見せる文は短くする（7章）。

## 0. いちばん大事な3つ
1. **作画はリリス基準**：全員の線・塗り・明暗・つや・細かさ・頭身の感じを、リリスに合わせる（1章）
2. **作画がブレない**：同じキャラは全部の絵で同じ人・同じ服。ちがうキャラでも同じ絵描きが描いたように見える（2章）
3. **エフェクトが入る前提で描く**：技の出どころが見えて、エフェクトが入る空間がある（3章）

## 1. 画風の見本（リリス）
- リリスを高画質で描き直した4ポーズ（P01・P02・P05・P09。どれも今のポーズのまま）を **「画風の見本」** にする：`assets/characters/lilith/master/lilith_style_master.png`（ドライブ `monmusu-art/情報源_ChatGPT` にも同じ絵）
- できるまでの仮の見本：いまのリリスの16ポーズ（`assets/characters/lilith/poses/`。360×446 で小さい）
- 一度決めたら **描き直さない**。全キャラのデザイン探し・画風合わせの依頼に添える
- リリスの作画の特徴（Claude が見くらべる所）
  - 線：細くて濃い（こげ茶〜黒むらさき）。輪郭がくっきり。髪の毛束・レース・フリルの線が細かい
  - 塗り：アニメ塗りにグラデーション。明暗の差が強め。影に色がある（むらさき寄り）
  - つや：髪・肌・靴にシャープな白いハイライト
  - 顔：大きめの目にグラデーションとハイライト、しっかりしたまつげ、小さい鼻と口、大人っぽい表情
  - 体：すらりとした大人の体（7.5〜8頭身くらい）、長い脚、ヒール
  - 細かさ：金の飾り・宝石・レースの描きこみが多い
- 光の当たり方は見本と同じ（やわらかい正面寄りの白い光）。魔法や炎の色の照り返しは描かない（コードでのせる）

## 2. ブレない決まり
- **デザインは2段階**：決める間は自由（デザイン探し）→ しょーくんが選んだら `状態：固定`。固定のあとは服・髪・小物・色を1つも変えない
- **正式な見本**：固定したデザインで、合格した4ポーズの紙（ミュウの big2・big3 にあたるもの）。残りのポーズは全部、正式な見本を「元の絵」にした **編集方式** で作る。見本を見せて新しく描かせない
- **画像への指示は短い英語1文・1回に1か所**。最後に「Keep everything else exactly the same.」
- **1つの依頼に添える絵は2枚まで**（元の絵＋画風の見本、または元の絵だけ）。多いとまざる
- **見本は2種類で、もらう物を分ける**（GPT の指示にも書いた）：①画風の見本（リリス）＝線・塗り・明暗・つやだけ ②キャラの見本（そのキャラの合格した絵）＝顔・髪・体つき・服・小物・色。デザイン探しは②がないので、顔・髪・体つき・服は依頼書の文で描かせ、①からは画風だけ。体つき・頭身もキャラの設定のとおり（リリスの体型を全員にうつさない）
- **依頼ごとに新しいチャット**（1チャットで2〜3枚まで）。GPT は「依頼中を全部描く」ので、**Claude は `状態：依頼中` を一度に2〜3枚までにする**
- **Claude のブレ点検**（届いた絵ごと。見本と並べた1枚の点検画像を作って見る。1つでもダメならやり直し。「だいたい同じ」は通さない）
  - 画風：線の濃さと太さ／明暗の強さ／つや／色の段の数／細かさ（リリスとくらべる）
  - 顔：輪郭・目の形と色・まつげ・眉・口
  - 髪：色・長さ・量・前髪・毛先
  - 服と小物：設定書のチェックシートを全部
  - 体：頭身・肩はば・脚の長さ・体つき
  - 大きさ：1人の縦のピクセルがめやす以上（4章）
  - エフェクト前提：3章を全部
  - 個性：同じ番号のほかのキャラと、形（シルエット）がちがう（5章）
- やり直しは、ダメな所だけを編集方式で1か所ずつ。色のずれ・小さなはみ出し・切り抜きは Claude がコードで直してよい（形・顔・服はコードで直さない）
- **しょーくんが OK を出す所は3つだけ**（どれも並べた1枚の画像で見せる）：①デザインの固定 ②正式な見本 ③16ポーズのまとめ

## 3. エフェクトが入る前提の作画
- **出どころが見える**：手のひら・指先・武器の刃と先・本・しっぽの先・髪の毛先など、技が出る所を、髪・袖・翼・もう片方の腕でかくさない。ポーズごとの出どころは設定書の演技表に書く
- **空間をあける**：出どころのまわりと、敵のほう（右）に、こぶし2つ分くらいの空間。チャージ（P06）は手元、必殺技（P07）は出どころの先を広くあける
- **手**：5本の指を全部描く。手のひらの向きは演技表のとおり（撃つ＝右へ／ためる＝向かい合わせ／支援＝上 など）
- **ガード（P09）**：胸〜腰の前に盾や膜が入る。顔は見えるように
- **足**：立つポーズは両足の裏が同じ床の線（床の魔法陣・だまり・衝撃波が入る）。床から離れるポーズは演技表に書く
- **光るもの・ゆれるもの・炎は、体の一部でもエフェクト**（例：しっぽの先の炎・剣の炎・オーラ）。形のデザイン（たれた毛先・角・うろこ）は絵に描く
- **絵に描きこまない**：弾・光・粒・煙・魔法陣・床の影・ぶれの線・スピード線・背景・文字（仕様書5章）

## 4. 大きさ（11/14 しょーくん：案A）
- **戦闘の16ポーズ**：1枚に4人を横一列（1536×1024）→ 1人の縦 **約700px 以上**（いまのミュウと同じ）
- **ガチャ・図鑑の1枚絵**：合格した P14 を元の絵にして、1枚に1人（1024×1536）→ 縦 **約1400px**（`<id>_P14_sexy_hd.png`）
- 4人の紙は、足の裏を同じ高さ・同じ大きさ・同じ頭身でそろえる（Claude が切り分けてそろえる）
- 保存は透明の PNG（マスター）、表示用は WebP（`tools/make_web.py`）
- リリスは 360×446 → 全部この大きさで描き直す。終わったら character.json の `scale` をはずす
- 身長の差は設定書の「身長」に書き、表示は character.json でそろえる

## 5. 個性（性格と演技表）
- 番号（P01〜SP02）は全キャラ共通の **役割**。形は **性格と戦い方** で決める。ほかのキャラのポーズを写さない
- 設定書（`docs/characters/<id>_design_master.md`）に、かならず書く（この順で決める）：
  1. 性格・体のクセ（しぐさの速さ・重さ・よくする手の形）
  2. **攻撃手段の表**（5-2。攻撃手段も個性・11/14 しょーくん）
  3. **16ポーズの演技表**：1ポーズ1行で「形・表情・出どころ・空間」。攻撃まわり（P04〜P07・P09・SP01・SP02）は攻撃手段の表から決める。しょーくんの OK で `状態：固定`
- 性格（11/14 しょーくん OK）

| キャラ | 性格 | 体のクセ |
|---|---|---|
| リリス | 余裕たっぷりの大人の誘惑。上品 | しぐさはゆっくり。流し目。本を持つ |
| ミュウ | 天真爛漫でいたずら好き | ぷるんと弾む。ちょこまか動く。表情がころころ変わる |
| ヴァルカ | 誇り高い姉御肌。仲間を守る | どっしり構える。腰を落とす。大剣は重そうに |
| コハク・フェン | （作る前に決める） | |

- Claude の点検：同じ番号を全キャラ並べて、形が同じに見えたらやり直し

### 5-2 攻撃手段（11/14 しょーくん：攻撃手段も個性。モーションも変わる）
- 剣・体当たり・魔法・投げる・爪・弓など、**攻撃手段はキャラごとにちがう**。手段が変わると、ポーズの形も、体の動き（モーション）も、エフェクトの出どころも変わる
- 設定書の **攻撃手段の表**（技ごとに1行）：

| 技 | 名前 | 手段 | 技の型（仕様書9章） | ポーズの流れ | 体の動き | 出どころ | 当たり方 |
|---|---|---|---|---|---|---|---|
| 通常攻撃・必殺技・支援・ガード・SP01・SP02 | 技の名前 | 例：手のひらから撃つ／大剣で斬る | 例：単発弾・斬撃・突進 | 例：P04→P05→P12 | 例：その場／一歩踏みこむ／敵の前まで突進して戻る | アンカー名 | 例：まっすぐ飛ぶ／目の前を斬る／地面を伝う |

- 手段ごとのめやす（形が決めつけにならないよう、最後は設定書が正）

| 手段 | P04 予備動作 | P05 攻撃の瞬間 | 体の動き（コード） | 出どころ（アンカー） | 作画で気をつけること |
|---|---|---|---|---|---|
| 魔法を撃つ | 手元に力をためる | 手のひらを敵へ | その場 | 手のひら `palm` | 手のひらの前をあける |
| 投げる | 腕を後ろへ引く | 腕を前へ振り抜く | その場・体をひねる | 手のひら（弧をえがいて飛ぶ） | 振り抜いた手の先をあける |
| 剣で斬る | 剣を振りかぶる | 剣を振り抜く（刃は体の右前） | 一歩踏みこむ → 戻る | 刃 `weapon_edge`・刃の先 `weapon_tip` | 刃が全部見える・刃が顔に重ならない・刃の上に炎や光を描かない |
| 叩きつけ | 武器や拳を頭の上へ | 地面へ叩きつける | 小さく跳ぶ → 着地 | 武器の先と足元（地面を伝う衝撃波） | 足元の右をあける |
| 突進・体当たり | 身を低くためる | 肩や体ごと前へ | 敵の前まで走って当たり、戻る（残像） | 体の前 `body_front` | 前のめりでも足が床の線 |
| 爪・連撃 | 爪をかまえる | 腕を振り抜く | すばやく近づく・何回か当たる | 爪の先 | 指と爪が全部見える |
| 弓 | 弦を引く | 放った形 | その場 | 弦の位置（矢が飛ぶ） | 弓と弦が全部見える |

- **体の動き** はエンジンの `actorParams`（`dx` 前後・`dy` 上下・`tilt` かたむき・`sx/sy` のび縮み）で motions.js に書く。近接（斬る・突進・爪）は敵の目の前まで動いて当てる。新しい手段が出たら、その動きの道具をエンジンに足して、次のキャラも使えるようにする
- 出どころのアンカー（`weapon_edge`・`weapon_tip`・`body_front` など、仕様書5-2）はポーズごとに character.json に書く
- 技とポーズは1対1にしない（仕様書9-4）。同じポーズでもエフェクトを変えれば別の技にできる

## 6. エフェクト
- **形と塗りは全部 ChatGPT の絵**（世界観をそろえる）。コードがするのは、動き・タイミング・位置・大きさ・回転・すける具合・重ね方・道にそって伸ばす／曲げる、だけ
- コードで描いてよいのは、形のないものだけ：体への色の照り返し・画面のフラッシュ・揺れ・暗くする
- 絵がないあいだはコードの仮の絵（エンジンはそうなっている）。**全部 GPT の絵になったら完成**
- **エフェクトの画風の見本**：合格したエフェクトの紙（いまはリリスのハート `fx_lilith_hearts1.png`）を、次のエフェクトの依頼に添える。キャラの色はキャラごと、形は使い回しすぎない（仕様書11章）
- **いつものエフェクト**（待機・歩行もふくむ全ポーズ。戦闘不能では消える）

| キャラ | いつものエフェクト |
|---|---|
| リリス | 小さなハートが2〜3個、体のまわりをゆっくり回る（体の前と後ろを行き来する）・蝶が1〜2匹・足元にうすいむらさきの霞 |
| ミュウ | 髪の毛先・袖布のすそ・指先からしずく（のびる→ふくらむ→ちぎれる→落ちる→だまりに残る）・足元に形のちがうだまりが2〜3個 |
| ヴァルカ | 火の粉が下から舞い上がる・しっぽの先の炎がゆらぐ・剣のまわりの熱気のゆらぎ（デザイン固定のあとに決め直す） |

| キャラ | いまコードか前の絵のもの | GPT の紙（2×2 で4つずつ） |

## 7. ChatGPT の癖と対策（11/14 までにわかったこと）
| 癖 | 対策 |
|---|---|
| 長いチャットだと顔が変わる・前のキャラ（猫耳メイドなど）がまざる | 依頼ごとに新しいチャット。プロジェクトのメモリは「プロジェクトのみ」 |
| 見本を見て新しく描くと別人になる・服をアレンジする | 合格した絵を「元の絵」にして編集（編集方式） |
| 直しを頼むと全体を描き直して別人になる | 画像への指示は短い英語1文・1回1か所・Keep everything else exactly the same |
| 日本語の依頼を自分の言葉に言いかえる | 「画像への指示（このまま使う）」を言いかえず渡す |
| 「〜しない」と書くと、その物が出る | 描かない物の名前を依頼に書かない。言いたいことは「〜する」で書く。描かない物は GPT のプロジェクトの指示だけに |
| 長い決まりを読むと、かえってくずれる | GPT に見せる決まりは短く。くわしい決まりはこのファイル（Claude 用） |
| 4K を頼んでも拡大だけ（約150万ピクセルまで） | 1枚の人数で細かさを決める（4章） |
| 透明が白とグレーのチェック柄になる | 無地の緑 #00FF00 で描かせて、Claude が消す |
| 絵にエフェクトを描くと、あとで直せない | キャラの絵は素のまま。エフェクトは別の紙 |
| 2枚の絵を渡すと、両方をまぜる（見本の服や色がうつる） | 画風を移すときは1枚だけ試して Claude が確かめてから続ける。添える絵は2枚まで |
| 画像を情報源に入れても同期されない | 描く前に毎回ドライブのフォルダを開かせる |
| 体の部位を強調するポーズに寄せる | 依頼にないポーズを描かない（README の 16+ の決まり） |
| 「見本と同じに」と言うと、画風の見本（リリス）の顔・服・体型までうつす | 見本を2種類に分けて、もらう物を指示に書く（2章） |
