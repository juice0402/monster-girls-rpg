# モン娘×牧場スローライフ 設計（記号 monmusu・名前はまだ）

最終更新：2026-11-16。このゲームの設計の正。決めたら、ここを書きかえる。キャラと世界は docs/CHARACTERS.md。

## どんなゲーム
- 牧場スローライフに、モンスター娘をあわせる（イメージはスターデューバレー・ルーンファクトリー）。しょーくんの「いつか作りたかった超大作の本命」
- 柱：モン娘と仲よくなる（親密度）＋ 家を改築して部屋をふやす → 一緒に暮らす → 農業を手伝ってくれて、自動化がすすむ
  - 例：スライム娘＝水やり、ドラゴン娘＝岩をくだいて石集め
- 地図は牧場と街など。マップメニューから行きたい所をタップして移動する
- 街に住むのはモン娘だけ。人間は主人公ひとり。お店の人もみんなモン娘で、全員と仲よくなれる
- RPG として、主人公との掛け合い・キャラ同士の掛け合いを大事にする（相関図と裏設定は docs/CHARACTERS.md）
- ほかの作品の名前・キャラ名は、絵の指示や依頼書に書かない（参考にするのは遊びの形だけ）

## 決まったこと（2026-11-16 しょーくん）
- 色っぽさ：**ちょっとだけ大人っぽい**
  - 立ち絵のモン娘は、はっきり大人の顔と体つき
  - 衣装はかわいい・おしゃれな服で、露出はひかえめ。水着・ハイレグ・胸元やおなかの大きな開き・色っぽいポーズは描かない（ガチャ版は露出のある衣装で Codex に断られた）
  - ちびドットのキャラには、露出も色っぽいポーズも入れない（ちびにセクシーは組み合わせない）
  - 年齢区分のめやすは 9+（出すときに【ios】で確かめる）
- お金：**無料＋広告がベース**。のちのち DLC・衣装セット・追加シナリオを売りたい。ガチャはなし
  - 広告や課金で「運で増える」しくみは入れない（プロジェクトの claude/game-art-rule.md の「しくみ」）
  - DLC・衣装セットを売る前に、司令塔で特商法の表示を決める
- 絵：**基本はドット絵。立ち絵と吹き出し（会話）の絵だけ Codex**
  - ドット絵（畑・作物・家・小さなキャラ）は、まずコードで描く（C）。コードでむずかしい背景・アイテムは Canva の AI（A）
  - 立ち絵・会話の顔は同じキャラを何枚も描くので Codex（art-requests/ と AGENTS.md・@codex と GH_TOKEN のいまのしくみ）。game-art-rule の「断られたあとの決まり」を守る（前の衣装の絵を元の絵にしない）
- リポジトリ：monster-girls-rpg をそのまま使い、中身を刷新した。16+ のガチャ版はブランチ archive/gacha-v1 に残す。ガチャ版の絵と設計は、こちらに持ちこまない
- 作り方：専用チャット【monmusu】で手作業（夜のまとめ作業は使わない）
- 画面：縦持ち。操作はタップで移動（マスをタップすると歩いていって作業）。指でなぞると画面が動いて見わたせる（なぞりとタップを分ける・11/16 しょーくん）。右下の「自分にもどる」で戻る
- 道具：下の板のホットバーで持ちかえる（クワ・じょうろ・ハンマー・種。11/16 しょーくん「ツールのアップグレードも必要だから」）。えらんだ物でだけ作業し、ちがう物ならどれに持ちかえるか教える。収穫と野の花つみは何を持っていてもできる。道具にはレベルを持たせ、あとで強くできるようにする（強くする場所と中身は未定）
- 主人公：人間の女の子（初期名ミノリ）
- 1日の長さ：朝6時〜夜中2時、ゲームの10分＝7秒（約14分）。「寝る」でいつでも次の日。試す用に早送り（×8）
- 恋愛・結婚：**なし。同居は「家族のような暮らし」まで**（11/16 しょーくん）。えらばなかった案：告白→結婚まで。何人とでも一緒に暮らせる
- 同居に誘えるのは **♥4から**（11/16 しょーくん・試作1のまま）。えらばなかった案：♥6
- 本筋：**なし。キャラごとの小さな話を積むスローライフ**（11/16 しょーくん）。谷の霧はふんいきだけ。セオドラの霧の話・ルゥの核の話は、それぞれのハートイベントにとどめ、つなげて大きな謎にはしない。えらばなかった案：霧の秘密を本筋にする
- ドット絵の目標：スターデューバレー級、できればルーンファクトリーに迫る見た目（11/16 しょーくん）。進め方は相談中

## モン娘（くわしくは docs/CHARACTERS.md）
- クロエ（ドラゴン娘）：クールで物静かな職人。街の大工で、主人公の家を改築する。同居すると畑の岩をこぶしでくだいて石を集める
- ルゥ（スライム娘）：元気でちょっと天然。スライムの体にオーバーオールだけ（シャツなし）＋長靴。同居すると体から水を飛ばして水やり
- ネリネ（アルラウネ）：種屋「こぼれ種」の店主
- 次の試作から：セオドラ（町長）・ヴェラ（医者）・ハティ（宿屋）

## 試作1（src/ からビルドした index.html・台詞は src/data/dialogue.json）
- 春28日・牧場と街の2マップ・モン娘はクロエ・ルゥ（＋種屋のネリネ）・改築1回
- 遊びの流れ：耕す → 種まき → 水やり → 収穫 → 出荷箱（お金は次の朝）→ 岩をくだいて石 → クロエに改築を頼む（1500G・石30・2日）→ 部屋が2つふえる → 仲よくなったモン娘（♥4から）を誘う（街では「部屋を見に来て」）→ 次の朝、牧場で部屋を見て同居の場面 → その日から牧場で暮らして手伝う → 28日でまとめ
- 仲よくなる：話す（1日1回 +20）・贈り物（1日1回、大好き +80／好き +45／ふつう +20／苦手 −20）。100で♥1
- 作物：カブ（種20G・4日・45G）、ジャガイモ（50G・6日・110G）、イチゴ（100G・8日・70G・とったあと4日でまた実る）
- 体力100：耕す2・水やり1・岩くだき4
- 住人の1日：クロエは工房（8〜18時）→ 広場、ルゥは噴水のまわり（7〜19時）、ネリネは店の前（9〜17時）。同居後は牧場（クロエは昼から工房）
- データはその端末のブラウザに保存（寝たとき・20秒ごと・アプリを閉じたとき）
