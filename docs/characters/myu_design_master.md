## 基本
- 名前: ミュウ ／ 種族: スライム娘 ／ 役割: 後衛・妨害＆範囲
- 年齢: 成人（はっきり大人の女性に見える顔と体つき）
- 戦闘の向き: 右向き（右の敵と戦う）
- 画風: リリス（`assets/characters/lilith/poses/`）と同じ世界の、高品質な現代アニメ・ソシャゲ風。ダークファンタジーで可愛さと妖艶さの両立。つやのある塗り、細い線、金の細かい装飾

## 変えてはいけない特徴（チェックシート）
- [ ] 体: 半透明でつやのある **水色（ペールブルー）** のゼリー状の体。肌の色は全身同じ水色
- [ ] 髪: 腰より長い **水色のゲル状の髪**。毛先に向かって **薄紫〜紫** に変わり、毛先は液体のようにたれる形
- [ ] 耳: とがった耳（エルフ耳）、金のイヤリング
- [ ] 頭: **金のティアラ**、額の中央に **青い宝石**
- [ ] 目: **紫の瞳**。表情は明るくいたずらっぽい（待機は口を閉じたやわらかい微笑みでもよい）
- [ ] 衣装・胸と胴: **紫のホルターネックのレオタード風**、金のふち飾りと胸元の宝石
- [ ] 衣装・腰: 前に垂れる **紫の前垂れ**（金の刺しゅう、先に青い宝石の飾り）
- [ ] 衣装・腕: 二の腕から垂れる **半透明の紫の袖布**（すそが液体のようにたれる、金のふち）
- [ ] 小物: 金の腕輪（両手首）、左ももに金の飾りベルト、金の足首の飾り
- [ ] 靴: **紫のハイヒール**（金の飾り）
- [ ] 手: 指先まではっきり描く（5本の指・欠けなし）

- 裸・はだける・ずれる・性的なポーズは描かない
