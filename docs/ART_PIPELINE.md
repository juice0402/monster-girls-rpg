# 絵とエフェクトを作るしくみ（再現できる手順）

更新日：2026-11-14 夜（要件定義 `docs/ART_REQUIREMENTS.md` に合わせた）
**いちばん強い決まりは要件定義 `docs/ART_REQUIREMENTS.md`**（作画はリリス基準・ブレない・エフェクトが入る前提・大きさ・性格と演技表・エフェクトは全部 GPT・GPT の癖の対策）。この手順はそのやり方。制作仕様は `docs/CHARACTER_FX_MASTER_SPEC.md`、ChatGPT の決まりは `art-requests/README.md`

## 0. だれが何をするか
| | やること |
|---|---|
| しょーくん | ぽぽち（Claude）に1文で頼む → ChatGPT の新しいチャットに決まった1行を貼る → 「描けたよ」と伝える |
| ChatGPT（プロジェクト「モン娘ゲーム」） | `art-requests/` の `状態：依頼中` を描いて、ドライブ `monmusu-art` に PNG で保存するだけ |
| Claude | 依頼書を書く・ドライブから取りこむ・合否・切り分け・色の直し・アンカー・エフェクト・動きのページ・点検・GitHub・公開 |

## 1. しょーくんが言うこと（これだけ）
- Claude に：
  - 「○○（キャラ名）の16ポーズを作って」
  - 「○○の△△（技・飾り）のエフェクトを作って」（例：リリスのまわりを舞うハート）
  - 「描けたよ」（ChatGPT が保存したあと）
- ChatGPT に（毎回、プロジェクトの中の新しいチャットで）：
```
依頼中を描いて
```

## 2. キャラの16ポーズ（ミュウで成功した順番＋11/14 夜の要件定義）
1. **デザインを決める**：`docs/characters/<id>_design_master.md` を作る（リリス・ミュウのをまねる）。デザイン探しの依頼に **リリスの画風の見本** を添えて何案か描き、しょーくんが選んだら `状態：固定`
2. **性格と演技表**：設定書に性格・体のクセ・16ポーズの演技表（形・表情・出どころ・あける空間）を書き、しょーくんの OK で固定（要件定義5章）
3. **16ポーズの見本**：演技表から16ポーズを小さく1枚に（`all16`）。ポーズと服をそろえる地図になる
4. **正式な見本**：all16 の段を、4ポーズずつ大きく描き直す（1枚に4人・1人の縦 約700px 以上）。合格した2枚が「正式な見本」（`master/`・ドライブの `情報源_ChatGPT`）。しょーくんの OK
5. **残りは編集方式**：正式な見本を「元の絵」にして、ポーズだけ変える（`edit14`）。新しく描かせない。添える絵は2枚まで
6. **1か所ずつ直す**：ちがう所は、短い英語1文の「画像への指示」で1回に1か所（`edit_sp02`）
7. **ガチャ・図鑑の1枚絵**：合格した P14 を元の絵にして1枚に1人（縦 約1400px）。`<id>_P14_sexy_hd.png`
8. **ブレ点検**：届いた絵ごとに、画風の見本・正式な見本と並べた1枚を作って見る（要件定義2章のチェック。1つでもダメならやり直し）
9. **取りこむ**：ドライブ `monmusu-art` から `assets/characters/<id>/source/` へ（Google ドライブのコネクタでダウンロード）。合否は Claude（仕様書 13-1）
10. **切り分け**：
```
python3 tools/import_sheet.py <id> assets/characters/<id>/source/<シート>.png P01 P02 P03 P09
```
   - 背景（透明・緑・白・チェック柄）を消して、1人ずつ体ぴったりで `poses/` に保存
   - 色の直しは character.json の `recolor` に書いて `--recolor`（例：ミュウの胸元の肌色→体の水色）
11. **アンカー**：
```
python3 tools/anchors.py <id>
```
   - 足元（root）としずくの出どころ（drips）は自動。手のひら（palm）・指先（tip）・ガード（guard）・被弾点（hit）は、点検シート `scratch/<id>_hands_check.png` の目もりを読んで character.json に書く
   - 自動がまちがうポーズは、character.json の `manual` に名前を書くと上書きされない
12. **表示用の WebP**：`python3 tools/make_web.py <id>`
13. **ART.md**：絵ごとに「A・ChatGPT・作った日・依頼書」を書く（`claude/game-art-rule.md`）

## 3. 動きの試しページ
- 共通のエンジン：`assets/engine/motion-engine.js`（絵の切りかえ・アンカー・背景・敵・操作・点検用の `?m=&t=`）と `assets/engine/motion-page.css`
- 種類ごとのエフェクトの道具：`assets/engine/fx-gel.js`（ゲル・しずく・スライムだまり・膜。ミュウ）・`assets/engine/fx-magic.js`（魔法の光・魔法陣・床の魔法陣・光の粒・ハート。リリス。描いた魔法の素材 `assets/painted-vfx.js` も読む）
- キャラごと：`assets/characters/<id>/character.json`（アンカー・エフェクトの絵）と `assets/characters/<id>/motions.js`（16の動き・タイミング・エフェクト）
  - character.json の `scale`：絵が小さいキャラの拡大（ふつうは書かない＝1。リリスは 360×446 の絵なので 1.5735）
  - motions.js の CHAR に `background(flash)` を書くと、そのキャラの背景になる（リリスのむらさきの夜）。ページの色は `assets/characters/<id>/theme.css`
- ページ：`myu-motions.html` をコピーして `<id>-motions.html`。変えるのは名前・説明・`<script>` の3行
- 動きの作り方（仕様書10章）：準備（P04）→ ため（P06）→ 発動（P05/P07）→ 飛ぶ・当たる → 余韻（P12）→ 待機（P01）。`seq` に「何割の時刻でどのポーズか」を書く
- エフェクトは必ずアンカーから出す（空中から出さない）。しずく・粘液は「体から伸びる → ふくらむ → ちぎれる → 落ちる → 床に残る」

## 4. エフェクト・飾り・演出のパーツ（GPT に描いてもらう）
- 依頼書：`art-requests/fx/<id>_<名前>.md`（ひな形 `art-requests/_templates/fx_sheet.md`）
- 1枚に **2×2 で4つ**（1つ 700px くらいで描ける）。キャラ・文字は描かない
- 背景は2種類：
  - **光るもの**（ハート・魔法陣・光の粒・斬撃の光・着弾の光）→ **真っ黒 #000000**。取りこみで黒を透明にして、光を足す重ね方（screen）
  - **物っぽいもの**（ゲル・しずく・花びら・蝶・羽・帯）→ **本物の透明**（だめなら緑 #00FF00）
- 取りこみ：
```
python3 tools/import_fx.py <id> <シート>.png 名前_1 名前_2 名前_3 名前_4 --grid 2x2 --bg black
```
   - `assets/characters/<id>/fx/` に WebP、character.json の `fx` に登録（作った日・依頼書も）
   - 名前の最後の `_1 _2` は同じ種類のちがう形。エンジンの `painted('名前')` が1つえらび、絵があればコードの絵の代わりに使う
- 動き（飛ぶ・回る・ふくらむ・消える）とタイミングはコード。GPT の絵は「形と塗り」だけ
- **形のあるエフェクトは全部 GPT の絵にする**（要件定義6章）。コードで描いてよいのは形のないもの（体への色の照り返し・フラッシュ・揺れ・暗くする）だけ。どれを描き直すかは要件定義6章の表
- 依頼には **エフェクトの画風の見本**（合格したエフェクトの紙。いまはリリスのハート）を添えて、全キャラのエフェクトの塗りをそろえる
- **いつものエフェクト**（待機・歩行もふくむ全ポーズで出るもの。リリスのまわりを回るハート・ミュウの毛先から滴るしずく など）は、motions.js の全ポーズで出す（要件定義6章）
- UI の枠・ボタン・ロゴ・宣伝の絵は、これまでどおり Canva（`docs/DEVELOPMENT_HANDOFF.md` の役割分担）

## 5. 画像への指示のコツ（11/14 にわかったこと）
- 「画像への指示（このまま使う）」は **短い英語1文**。GPT に言いかえさせない（依頼書に「このまま渡す」と書く）
- **1回に1か所**だけ変える。いくつも直したいときは、1か所ずつ何回かに分ける
- 「〜しない」を並べない（書いた言葉の物が出る。例：猫耳と書くと猫耳が出る）。描かないものは GPT のプロジェクトの指示にまとめてある
- 依頼1つ（2〜3枚）ごとに **新しいチャット**（長いと顔が変わる・ほかのキャラがまざる）
- 細かさは1枚の人数で決まる：4人＝縦700px（標準）・1人＝縦1400px。4K を頼んでも細かくならない
- 色のずれ・切り抜き・小さなはみ出しは、描き直させずに Claude がコードで直す
- ほかの癖と対策は要件定義7章（2枚の絵を渡すとまざる・長い決まりでくずれる など）
