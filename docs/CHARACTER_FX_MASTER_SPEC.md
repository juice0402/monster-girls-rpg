# モン娘RPG｜キャラクター・モーション・エフェクト制作仕様書【完全版 v1.0】

> **制定日：2026-11-14**　／　**適用対象：全プレイアブルキャラクター、新規キャラ、追加スキル、戦闘UI、演出素材**  
> **位置づけ：制作時のマスター仕様（Source of Truth）**。本書の「採用」項目は今後の全キャラ制作の標準とする。変更する場合はバージョンを上げ、変更履歴を残す。

## 0. 最優先の決定事項

1. **ゲーム本体のキャラクターと、エフェクト・魔法弾・床効果を完全分離する。** キャラ素材に魔法陣、弾、光、爆発、粒子、背景を描き込まない。手や武器の欠損を後から切り抜いて補正する運用は禁止。
2. **1キャラの顔・髪・衣装・体型を先に確定し、全ポーズを同一キャラ資料から一括制作する。** 後から違う画像を参考に1枚だけ生成しない。画像生成では完全一致を保証できないため、全ポーズの目視比較・修正を必須とする。
3. **共通基本ポーズ14枚＋キャラ固有ポーズ1〜2枚、表情差分8種類を初期の制作基準にする。** 歩行は2枚を初期採用し、4枚化できる拡張枠を確保する。
4. **勝利専用ポーズは不要。勝利演出には「セクシーポーズ」を兼用する。** ガチャ・図鑑・鑑賞にも流用可能な全身ポーズとする。
5. **派手さは別レイヤーの高品質な素材と演出タイミングで出す。** やたら円を増やさず、床・手元・キャラ周辺・着弾・残留を役割分担する。キャラの顔や手を隠さない。
6. **必ず画面で確認し、合格した版だけ公開する。** 「コードの構文が通った」「GitHubのデプロイが成功した」ことと「見た目が完成した」ことは別の検査項目。

## 1. ゲームとアートの前提

|項目|制作基準|
|---|---|
|ジャンル|モン娘による放置型／自動進軍型の横スクロール2D RPG|
|パーティー|5体、前衛2体・後衛3体。基本は右側の敵に向かって戦う|
|対象|iPhone／iPad、ブラウザ実証版からアプリ化を目指す|
|美術|高品質な現代アニメ・イラスト表現を主軸にしたダークファンタジー、可愛さと妖艶さの両立（sexy_cute）|
|整合性|同一世界の照明、彩度、輪郭密度、宝飾表現、透過処理を揃える|
|実装|キャラポーズ切替＋小さな変形＋前後の独立演出レイヤー。外部Live2D制作を必須としない|
|制作時の優先順位|キャラの同一性 ＞ 破綻のない接地・手元 ＞ 動作の読みやすさ ＞ エフェクトの豪華さ|

**現在の参考実績**：リリスの待機呼吸・蝶・紫照り返し・演出タイミングは、制作手法の良い参考例。ミュウの以前の試作では、別人化、焼き込まれた魔弾、欠損した手、空中からの粘液、公開前のデバッグ表示などが発生した。これらを繰り返さないための仕様である。リリスの試作画面をそのまま全員にコピーせず、共通の技術だけを再利用する。

## 2. キャラクター固有デザインを固定する「マスター資料」

**2-1　制作前に必ず確定する内容**

- キャラ名・種族・設定上の成人年齢・役割・属性・性格・戦闘スタイル・体格・身長差・色の主従関係。
- 正面／右向き斜め／背面のデザイン確認図。髪の長さと分け目、目の色、瞳の形、顔立ち、角・耳・翼・尻尾・スライム部位などの固有シルエット。
- **衣装の設計図**：胸部・腰・手首・脚・靴・装飾・金具・紐・宝石・模様の位置・配色。脱着できる武器は独立素材で扱う。
- **エフェクトに覆われても欠損しない手のデザイン**：指先まで描く。攻撃・詠唱・支援ポーズでは掌の向きと発射点を明示。
- 質感の指定：布、革、金属、皮膚、ゼリー状の半透明、毛並み、羽根等をキャラごとに明記。
- キャラクター単独の**正式マスター立ち絵**と「ここから変えてはいけない特徴」のチェックシート。

**2-2　統一制作ワークフロー**

1. 正式マスター立ち絵を1枚選定・承認する。
2. 上記の正面・側面・背面・衣装・配色資料を作る。
3. すべてのポーズを同一マスターと資料を参照して制作する。可能なら一括で比較できるコンタクトシートも作る。
4. 同じ髪・顔・目・胸元の装飾・腰回り・足元・種族固有部位が揃うかを**1枚ずつ検査**する。
5. ポーズの修正が必要なら、独立した別人絵を混ぜず、同じマスターを参照して再調整する。
6. 承認済みのポーズ一式を「キャラ版」として凍結。以後のエフェクト調整で**マスター本体を再生成しない**。

|ID|ポーズ／用途|制作内容と注意|
|---|---|---|

|P02|歩行 A|右方向の第1歩、踏み出し。足の接地は共通基準。|

|P09|防御／ガード|身を守る、受け流す、バリア用。防御フィールド自体は別素材。|
|P10|被ダメージ|のけぞり、痛みや驚きの表情。HP0の姿と混同しない。|
|P11|戦闘不能|膝をつく、倒れるなど。過激な損傷描写は不要。|
|P12|発動後の余韻／決めポーズ|技を放った直後の復帰前ポーズ。残留FXと合わせられる。|
|P13|挑発／アピール|敵視、威嚇、魅了、誘惑、戦闘中の個性的なリアクション。|
|P14|セクシーポーズ【勝利兼用】|勝利・ステージクリア・ガチャ・図鑑・鑑賞で使用。別途「勝利専用」は作らない。|

**基本枚数の計算**：旧案の基本13枚に「チャージ／溜め」を独立させて14枚。P02・P03は歩行2枚として別カウント。全員分を同じ納品フォルダ構造に揃える。

**キャラ固有ポーズ（追加で1〜2枚・採用）**

- SP01：固有技ポーズ（例：リリスの誘惑、ミュウの伸縮・変形、狼娘の飛び込み、ドラゴン娘の炎斬）。
- SP02：必要に応じて追加する第2固有技／変形／タンク挑発／狐娘の回復の祈り等。
- 独自の技を多数持つ場合も、まずP04〜P08とSP01〜SP02を使い回す。**技ごとに異なる独立エフェクト**でバリエーションを出す。
- 将来拡張枠：歩行C／D、回避・ステップ、連撃途中、空中・ジャンプ、変身前後。初期制作では設計上の余地を残す。

**標準納品量**：**共通14枚 + 固有1〜2枚 = 15〜16枚／キャラ**、さらに表情差分8種。5人パーティーでは基本75〜80枚の全身ポーズ（歩行追加分は別）。

## 4. 表情・可動パーツ仕様【採用】

|E-ID|表情差分|用途|
|---|---|---|
|E01|通常|待機・汎用|
|E02|微笑み|会話・支援・勝利|
|E03|驚き|被弾・イベント|
|E04|怒り／真剣|通常攻撃・必殺技|
|E05|困り／照れ|イベント・交流|
|E06|うっとり／恍惚|魅了・セクシーポーズ・固有演出|
|E07|ダメージ／苦痛|被ダメージ、戦闘不能|
|E08|ウィンク|挑発・勝利・図鑑|

- まばたきは両目を閉じたパーツも別に管理。口の開閉や小さな呼吸に使うパーツが作れれば追加する。
- **可動切り出しの候補**：前髪・後ろ髪、尻尾、翼、耳、リボン、マント・スカート、武器、スライムの触手・液体部分。
- パーツを切り出しても背後が欠けないよう、隠れる部分の塗り足しを確保。難しい場合は全身絵の微小変形で代用してよい。

## 5. 素材の解像度・透過・座標設計【採用】

**5-1　原則**

- 各ポーズは高解像度**透過PNGマスター**として保管。Web表示用は画質確認後に透過WebP等を別途生成してよい。
- 同一キャラの全ポーズは**同一サイズの透明キャンバス**と共通原点を使用。初期標準例：1536×1536px（キャラや衣装の広がりで必要なら統一サイズを変更する）。
- 重要なのは形式上のキャンバス寸法ではなく、**描画時の足元接地点／身体スケール／向き／原点が一致**していること。全ポーズをゲーム内で同じ基準に合わせる。
- 髪や翼、手を伸ばす必殺技のために周囲に適切な透明余白を設ける。画像端で指先や装飾を切らない。
- 戦闘用は原則**右向き**。セクシーポーズP14は正面・振り向き構図も可。
- 背景・魔法陣・弾・属性光・粒子・爆発・床効果は本体素材に含めない。常設の衣装の宝石など、キャラ自身の造形は描いてよい。
- 元画像から不要な魔弾を消す際に手まで欠損させる方法は**不採用**。最初からエフェクト無しで製作する。

**5-2　アンカー（エフェクトを発生させる点）**

- 必須基準：`root_feet`（接地点）、`foot_L`、`foot_R`、`hand_L`、`hand_R`、`palm_out`（弾発生位置）、`face_front`、`head_top`、`chest`、`waist`、`back`。
- 種族・装備により追加：`tail_tip`、`wing_root_L/R`、`wing_tip_L/R`、`horn_L/R`、`hair_tip_*`、`staff_tip`、`weapon_edge`、`slime_tip_*`、`slime_body_edge_*`。
- **ポーズごとに座標が変わるので、各ポーズに個別アンカー表を記録する。** 向きや画像の縮尺・呼吸変形・攻撃時の動きを変えるなら、アンカーにも同じ変換を適用。
- スライム滴りのような体液FXは髪先や腕・脚等、**見えているキャラ本体の体表に明示的な発生点**を置く。透明部分を自動探索するだけの方式は、髪の空洞・浮遊アクセサリー・背景の残り絵を誤検出しうるため単独採用しない。
- アンカー目視確認用の赤い丸は**開発プレビューだけ**に表示。本番用HTMLでは強制非表示（デバッグモードの出荷禁止）。

**5-3　連結の検査**

- 手元FXの根元が指先・掌に一致するか。光る球で**指を覆い隠していないか**。
- 攻撃ポーズで手が完全に描かれているか、発射前後で手首が欠けないか。
- 足元FX・接地影は両足の靴底に対して自然な位置か。魔法陣なら固定サイズ、スライムなら**不規則な複数の粘液だまり**。
- 粘液の糸は**体表から伸びる → 先端が膨らむ → ちぎれる → 落下 → ぬめり床に残る**の連続動作。空中スタート禁止。

## 8. FXの機能別分類【6段階・採用】

|分類|目的|代表資産|
|---|---|---|
|A 溜め・詠唱|力が手元／胸元／足元に集まる|収束光、手元発光、オーラ、霞、床の起動|
|B 発射|発動の主役、視認しやすい飛翔体|単発弾、多段弾、ビーム、粘液弾、火球、氷塊、風刃、雷槍、闇塊、ハート弾|
|C 軌道|弾や武器が移動した情報を残す|弾尾、残像、飛沫、粒子、糸引き粘液、蝶、羽根、花びら|
|D 命中|敵との接触と結果を明確にする|爆発、着弾リング、斬撃閃光、拘束、氷結、闇煙、粘液飛散|
|E 残留|攻撃後も世界に効果が残る|魔法陣、スライムだまり、黒霧、炎、バフ輪、状態異常紋、光粒|
|F 常時|戦闘中もキャラの種族らしさを見せる|蝶、湯気、キラキラ、羽毛、粘液滴、尻尾・翼の微動|

**すべて同時点灯させない。** 単発攻撃でも「予備動作→溜め→放出→軌道→命中→余韻」、多段攻撃なら「溜め→複数回放出→連続ヒット→残留」という順番と強弱を設計する。

## 9. 技／アクションの型【全採用：技は追加可能な構造に】

**9-1　物理技テンプレート：5種類**

1. 斬撃／武器軌跡
2. 突進／押し込み
3. 連撃／多段命中
4. 飛び込み／跳躍
5. 叩きつけ／地面衝撃波

**9-2　魔法・支援テンプレート：12種類**

1. 単発弾　2. 多段弾　3. 貫通ビーム　4. 範囲爆発　5. 設置型　6. 追尾弾　7. 拘束　8. 吸収　9. バフ　10. デバフ　11. 回復　12. 召喚

**9-3　モン娘固有技テンプレート：11種類**

1. 誘惑　2. 魅了　3. 毒／粘液　4. 夢／幻惑　5. 吸収・吸精をイメージした非露骨な魔力吸収　6. 羽ばたき衝撃波　7. 尻尾打撃　8. 体液・粘液拘束　9. 花粉／香気　10. スライム包み込み　11. エネルギー触手・変形攻撃

**9-4　技のデータ設計**

- 1技を `技ID / キャラID / 攻撃分類 / 使用ポーズ / 発生アンカー / 発動準備秒数 / 発射秒数 / 飛翔時間 / 命中時刻 / 余韻秒数 / エフェクト構成 / ヒット回数 / 属性 / 対象 / 威力・効果 / サウンド / 画面演出` で定義。
- 既存ポーズで新技を実装できるよう、**ポーズとスキルを1対1に結びつけない**。同じP07でも「炎剣」「氷結」「回復」では別のFXを構成できる。
- 新しい技を増やす場合は、**新規ポーズが本当に必要か**を先に確認。可能なら既存ポーズ＋専用FXで制作し、キャラの同一性を保つ。
- 実際のダメージ判定は見た目の弾より先走らない。着弾時刻とダメージ表示・敵の被弾反応を同期する。

## 10. 技演出の時間設計【段階ごとに独立制御】

|段階|アニメーション|初期調整の目安（技により変更）|
|---|---|---|
|T0 待機|呼吸・常時FX|常時ループ|
|T1 準備|P04へ移行、足元や掌の微光が先に立ち上がる|0.15〜0.45秒|
|T2 詠唱／チャージ|P06、体表への照り返し、粒子が徐々に増える|0.4〜1.2秒|
|T3 発動|P05またはP07、光量のピーク、飛翔体を生成|0.1〜0.35秒|
|T4 飛翔／命中|FXの飛翔・軌跡・敵の被弾|0.2〜0.8秒|
|T5 余韻|P12、残留粒子・蝶・粘液・霧を遅れてフェード|0.5〜1.8秒|
|T6 復帰|P01に自然に戻り、常時FXだけ残る|0.15〜0.35秒|

- 溜め・発射・命中・余韻のピークを**別々に**設定。すべて一瞬だけ同時点灯する演出は不採用。
- 常時FXは発動前後で完全消滅させない。例：リリスの蝶は待機中は少数、詠唱中に増加、命中後も数が減りながら残る。
- 床の魔法陣・スライムだまりの**輪郭やサイズを不自然に伸縮させない**。明るさ・流れ・小さな表面反射で変化を表現。
- 大技のときだけカメラ振動、暗転、ズーム、画面縁の光などを選択的に追加。通常攻撃で常に全画面を埋めない。

## 11. キャラごとの固有エフェクト【各5〜10種・採用】

### リリス（サキュバス／後衛・魔法）
- 待機中の少数の蝶、詠唱時に増える蝶。
- 紫の体表反射光（シルエットマスク）、紫の魔力霞、魅了粒子／ハート、手元の魔力輪。
- 発射弾の紫系魔法、着弾の蝶・花びら・魅了紋、発動後の余韻。
- **参考の実装資産**：既存のリリスの演出を「手本」としつつ、本人のキャラ絵にFXを焼き込まない。

### ミュウ（スライム／後衛・妨害＆範囲）
- 常時：わずかな呼吸・ぷるぷる、体表に沿った粘液の糸・落下する滴。
- 足元：**不規則なスライムだまりが複数点在する**。輪っか状の床魔法陣は使わない。
- 詠唱：掌の周囲で透明なゲルが収束。指は必ず見える。
- 攻撃：手元から分離した半透明ゲル弾、糸引き尾、粘液の分裂と拘束。
- 命中：ぬめり・粘性による絡みつき、残留粘液。単純な水滴／水の波紋表現にしない。
- **重要な禁止事項**：空中発生の粘液、赤いデバッグ点、魔弾付きのキャラ立ち絵、魔弾削除で手が欠ける加工。

### ヴァルカ（ドラゴン娘／前衛・タンク；候補）
- 炎・鱗の輝き、剣への炎の収束、盾／鎧の反射光、熱気、火の粉、炎の斬撃、接地衝撃波。

### コハク（九尾の狐娘／後衛・回復支援；候補）
- 狐火、護符、尾の淡い残光、回復光柱、桜／花びら、祝福の粒子、バフ輪。

### フェン（狼娘／前衛・高速攻撃；候補）
- 走行残像、双剣の軌跡、爪・刃の閃光、連撃スパーク、疾走風、瞬間移動の残像。

※候補キャラ名・詳細デザインは正式マスターの制作前に個別承認する。**全員のFXカラーや形状は使い回しすぎない**。

## 14. 制作と承認の段階【全キャラ共通】

1. **デザイン固定**：キャラのマスター・衣装設定を承認。
2. **ポーズセット制作**：共通14＋固有1〜2を一括で揃え、同一人物か並べて審査。
3. **可動差分**：顔8種とまばたき、種族の揺れるパーツを準備。
4. **接地点とアンカー**：足元・手元・体表の座標をポーズ別に計測、可視化テストで確認。
5. **常時FXと待機ループ**：派手さより自然さ。ここを最初に承認。
6. **技ごとのFX設計**：6分類と36汎用素材、キャラ固有5〜10素材から組み立てる。
7. **技テスト**：待機→詠唱→攻撃→命中→余韻→待機のフルサイクルを確認。
8. **5人パーティーに統合**：前衛2・後衛3の重なり、戦闘判定、歩行、HP、ダメージ、進軍を確認。
9. **公開・記録**：制作基準、アセット版、テスト結果、公開URLを残す。

**承認の単位**：「絵の統一感」「ポーズ」「待機FX」「通常攻撃FX」「必殺技FX」「統合ゲーム動作」を分ける。修正対象以外の承認済みパーツを勝手に差し替えない。
