# 絵の依頼書（ChatGPT へ）

キャラの絵は、このフォルダの依頼書で描いてもらいます。
依頼書を書くのも、できた絵を確かめるのも Claude です。ChatGPT のお仕事は **「依頼書どおりに絵を描いて保存する」だけ** です。

## ChatGPT の決まり（必ず守る）
1. **絵を描いて保存すること以外はしない。** HTML・JavaScript・CSS・docs・依頼書・ほかの絵・エフェクトには触らない（読むのはよい）
2. **GitHub には何も書かない**（読むだけ）。絵の保存は Claude がする
3. `状態：依頼中` の依頼書を、ファイル名の順に全部描く。1つの依頼書で1枚
4. 描く前に、依頼書にある **見本の絵** と **デザイン設定** を必ず見る
5. できた絵は **Google ドライブのフォルダ `monmusu-art`（いちばん上。中のフォルダには入れない）に PNG で保存する**。ファイル名は依頼書の「保存先」の名前（例：`myu_P01_idle.png`）。Claude がそこから取りこむ
   - ドライブに保存できないときは、PNG ファイルとしてチャットに出す（しょーくんがドライブに入れる）
   - 2026-11-14：GitHub への画像の保存（画像のまま・base64 の文字）はどちらもできなかったので、ドライブ経由に決めた
6. 依頼書の `状態` は書きかえない（Claude が書く）
7. 描けなかったときは、チャットに依頼書の名前と理由を1行で書く
8. 年齢区分 16+ の決まり：みんな大人に見える体と顔／露出は水着くらいまで／裸・はだける・性的なポーズは描かない
   - **体の部位を強調するポーズも描かない**：後ろ姿でお尻を見せる・お尻や胸に手をそえる・四つんばい・寝そべって誘う など（セクシーポーズは「上品な決めポーズ」まで）
   - **依頼書にないポーズを描かない**（ピンナップ風のポーズに変えない）

## デザインの2段階（大事）
1. **デザインを決める段階**：服・髪などを変えてよい（依頼書に「デザイン探し」とあるとき）
2. **デザイン固定のあと**：デザイン設定の `状態：固定` のキャラは、**全ポーズを見本とまったく同じデザイン** で描く。服・髪型・小物・色を1つでも変えたら、そのポーズはやり直し

## 1枚ごとの見直し（2026-11-14〜・必ず）
1. **描く前に毎回**、依頼書の見本の絵をドライブから読みこみ直す（2枚目以降も、前の絵の記憶で描かない）
2. **描いたあと**、見本と並べて「同じキャラか」を見直す。ちがったら1回だけ描き直す
3. キャラの種族を変えない。**猫耳・けもの耳・しっぽ・メイド服・エプロン・カチューシャなど、デザイン設定にないものは足さない**
4. 前に話したほかのキャラ（ほかのチャットや思い出した内容）をまぜない。描くのは依頼書のキャラだけ

## まとめて描く（1回の依頼で最後まで）
- `状態：依頼中` の依頼書を **キャラ名のフォルダ順・ファイル名の番号順** に、全部描き終わるまで続ける。途中で確認を待たない
- **1枚描くたびに、すぐドライブに保存** してから次へ進む（途中で止まっても、そこまでの絵が残るように）
- 1つの依頼書に何枚もあるとき（表があるとき）は、表の順に1枚ずつ描いて保存する
- **1枚が2回やってもうまくいかないときは、その番号を飛ばして次へ進む**（止まらない）。飛ばした番号と理由は、最後の一覧にまとめて書く。飛ばした分は Claude が依頼書を直して、あとで頼み直す
- **チェック柄が出たときは**、透明にこだわらず、その絵を **無地の緑 #00FF00 一色の背景** で描き直して保存してよい（緑は Claude が消す）
- 1回の返事で全部描けないときは、そこで止めて「次は ○○ から」と書く。しょーくんが「続けて」と送ったら、その続きから再開する
- **保存しないのは2つだけ**：①デザイン（顔・服・小物・色）が「正式な見本」と明らかにちがう ②16+ の決まりをやぶっている（後ろ姿でお尻を見せる など）
- **それ以外は、2回目の絵（よいほう）を必ず保存する**。ポーズの細かい所（足の向き・手の高さ など）・透明・余白・大きさが少しちがっても保存して、ちがう所を一言そえて次へ進む。**合否は Claude が決める**（保存しないと Claude が確かめられない）
- 全部終わったら、保存したファイル名の一覧だけを返す

- **「表の何人目と同じ形」と書いてあっても、描くのはその1人だけ**（見本の表をまるごと描き直さない）

## ポーズの形はキャラごと（大事）
- P01〜P14・SP01〜SP02 の番号は、全キャラ共通の **「役割」**（待機・通常攻撃・必殺技…）。**どんな形にするかは、そのキャラの戦い方で決める**
  - 例：通常攻撃（P05）→ 魔法使いは手のひらを向けて撃つ／剣士は剣を振る／弓使いは弦を引いて放つ／体当たりのキャラは体ごと突っこむ
  - 例：詠唱・チャージ（P06）→ 魔法使いは手元に力を集める／剣士は剣をかまえて力をためる
- 「腕を伸ばす＝攻撃」のように決めつけない。**依頼書に書いた形が正**
- 依頼書には、攻撃の **出どころ**（手のひら・武器の先・体全体 など）も書く。Claude はそこからエフェクトを出す

## 絵の大きさのめやす（2026-11-14 わかったこと）
- ChatGPT のアプリで描ける絵は、だいたい150万ピクセルまで（例：2172×724）。4K を頼んでも、拡大になるだけで細かくはならない
- だから1枚に描く人数で、1人あたりの細かさが決まる：16人→縦300px くらい／8人→縦500px くらい／**4人→縦700px くらい（標準）**／1人→縦1400px くらい（ガチャの大きな絵など）
- 長いチャットで続けると、顔や服が変わったり、ちがうキャラを描き始めたりする。**依頼1つ（または2〜3枚）ごとに新しいチャットにする**

## 並べ描き（シート）方式
- 1枚の横長の絵に、**同じキャラの4ポーズを横一列** に並べて描く（同じ1枚の中だと、顔と服がそろいやすい）
- 4ポーズとも **同じ大きさ・同じ頭身・足の裏が同じ高さ（同じ床の線）**。ポーズ同士は重ねず、**間をあける**
- 並び順は依頼書のとおり（左から1・2・3・4）
- シートは **同じ ChatGPT のチャットで続けて** 描く。2枚目からは、そのチャットで前に描いたシートとも同じ人・同じ服にそろえる
- Claude が1ポーズずつ切り分けて、足の位置と大きさをそろえる

## 絵の共通の決まり
- 背景は **本物の透明**（PNG のアルファ）。**透明を表す白とグレーのチェック柄（市松模様）を絵として描かない**。本物の透明にできないときは、無地のグレー #808080 一色
- **見本の絵は、描く前に毎回 Google ドライブの `monmusu-art/情報源_ChatGPT` フォルダを開いて見る**（PNG はプロジェクトの情報源に同期されないため）。ない絵は、ドライブの `monmusu-art` の中を名前でさがす
- 見本の絵が読みこめないときは、見ないまま描かずに「見本が見られない（ファイル名）」と書いて止まる
- 1枚ずつの依頼は縦長 **1024×1536**、シートは **横長でできるだけ大きく（1536×1024 以上）**。頭から足先まで全身が入り、上下左右に余白をとる（指先・髪・ヒールを画面の端で切らない）
- 戦闘のポーズは **右向き**（右の敵と戦う）
- **絵に描きこまない**：魔法・弾・光・粒子・魔法陣・床の影や光・背景・文字・ロゴ・サイン
- 手は指先まで描く。手の前に何も重ねない

## 状態の意味（Claude が書く）
- `依頼中`：ChatGPT が描く
- `確認中`：絵が届いて Claude が確かめている
- `OK`：合格。Claude が `main` に取りこむ
- `やり直し`：理由を書いた上で `依頼中` に戻す
- `取り下げ`：描かなくてよい
- `保留`：いまは描かない（Claude が `依頼中` に戻すまで待つ）
