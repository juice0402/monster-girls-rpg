# 絵の依頼書（ChatGPT へ）

キャラの絵は、このフォルダの依頼書で描いてもらいます。
依頼書を書くのも、できた絵を確かめるのも Claude です。ChatGPT のお仕事は **「依頼書どおりに絵を描いて保存する」だけ** です。

## ChatGPT の決まり（必ず守る）
1. **絵を描いて保存すること以外はしない。** HTML・JavaScript・CSS・docs・依頼書・ほかの絵・エフェクトには触らない（読むのはよい）
2. 保存するのは **ブランチ `gpt-art` だけ**。なければ `main` から作る。`main` には書かない
3. `状態：依頼中` の依頼書を、ファイル名の順に全部描く。1つの依頼書で1枚
4. 描く前に、依頼書にある **見本の絵** と **デザイン設定** を必ず見る
5. 保存先とファイル名は依頼書のとおり。PNG で保存する。やり直しのときは同じ名前で上書きする
6. 依頼書の `状態` は書きかえない（Claude が書く）
7. 描けなかった・保存できなかったときは、`gpt-art` ブランチの `art-requests/_gpt-notes.md` に、日付・依頼書の名前・理由を1行で書く
8. 年齢区分 16+ の決まり：みんな大人に見える体と顔／露出は水着くらいまで／裸・はだける・性的なポーズは描かない

## 絵の共通の決まり
- 背景は **透明**（できなければ、無地のグレー #808080 一色）
- 縦長 **1024×1536**。頭から足先まで全身が入り、上下左右に余白をとる（指先・髪・ヒールを画面の端で切らない）
- 戦闘のポーズは **右向き**（右の敵と戦う）
- **絵に描きこまない**：魔法・弾・光・粒子・魔法陣・床の影や光・背景・文字・ロゴ・サイン
- 手は指先まで描く。手の前に何も重ねない

## 状態の意味（Claude が書く）
- `依頼中`：ChatGPT が描く
- `確認中`：絵が届いて Claude が確かめている
- `OK`：合格。Claude が `main` に取りこむ
- `やり直し`：理由を書いた上で `依頼中` に戻す
