# 絵の依頼書（Codex）

- 1枚の絵に1つの依頼書：`art-requests/<キャラか種類>/<名前>.md`。Codex への決まりは [../AGENTS.md](../AGENTS.md)
- このファイルと、`_` で始まるファイルは依頼書ではない
- 1つのチャットが同時に「依頼中」にするのは2つまで
- 断られたら、その依頼書に「断られた：日付・何が」を1行残す（同じ文・同じ元の絵で出し直さない）
- ガチャ版（archive/gacha-v1）の絵は、元の絵にしない

## ひな形

```
# <名前>
状態：依頼中
ブランチ：art/<名前>
元の絵（リポジトリ）：<パス>
保存先（リポジトリ）：<パス>.png
画像への指示（このまま使う）：<短い英語1文>
点検：<ここがちがったら描き直し>
断られた：なし
```
