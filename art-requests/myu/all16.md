# ミュウ 16ポーズを1枚に（試し）

状態：依頼中
依頼日：2026-11-14
保存先：Google ドライブのフォルダ `monmusu-art` に `myu_all16.png`（PNG・背景は透明）
ねらい：16ポーズを1枚の中で描くと、顔と服がいちばんそろう。Claude が16個に切り分けて背景を消す

## 見るもの
- デザイン設定（**状態：固定**）：`docs/characters/myu_design_master.md` のチェックシートを全部守る
- 正式な見本：`assets/characters/myu/master/myu_ref_B.png`（顔・髪・服・小物・色は **この絵とまったく同じ**。ポーズだけ下のとおりに変える）
- 画風の見本：`assets/characters/lilith/poses/lilith_P01_idle.png`・`lilith_P05_attack.png`
- 決まり：`art-requests/README.md`（ポーズの形はキャラごと・描かないもの）

## 並べ方
- **4列×4段** の表のように並べる。上の段から下の段へ、各段は左から右へ
- できるだけ大きな絵で（正方形か縦長。2048 以上が描けるならそれで）
- 16ポーズとも **同じ大きさ・同じ頭身**。各段で **足の裏が同じ高さ**。ポーズ同士は重ねず、**はっきり間をあける**（切り分けるため）
- 戦闘のポーズは右向き（P14 だけ正面〜少し右向きでよい）。手は指先まで描く
- 描かないもの：空中のしずく・床のスライムだまり・ゲルの弾・魔法・光・もや・粒子・床の影・背景・文字・番号

## 1段目｜落ち着いたポーズ（左から）
1. **P01 待機／立ち絵**：体はやや斜めで、顔と体は右を向く。両足を肩幅くらいに開いて床に立つ。両手は体の横〜腰のあたりで、手のひらは少し開く。やわらかい微笑み
2. **P02 歩行 A**：右へ歩く1歩目。前の足を右へ踏み出して、かかとから床につく。後ろの足はつま先で床につく。腕は自然に振る
3. **P03 歩行 B**：P02 の反対の足が前（P02 と交互にすると歩いて見える）。それ以外は P02 と同じ
4. **P09 防御／ガード**：体を少し後ろへ引いて床に踏んばり、両手のひらを右（前）に向けて胸〜腰の前にかざす（ここにゲルの盾を Claude が重ねる）。真剣な顔

## 2段目｜攻撃のポーズ（左から）
1. **P04 攻撃予備動作**：右手を後ろに引いて力をためる。左手は前へ。視線は右の敵。P05 にそのままつながる形
2. **P05 通常攻撃**：ミュウは手のひらからゲル弾を撃つので、腕を右へまっすぐ伸ばし、手のひらを開いて右の敵に向ける（見本 B に近い形。ここからゲル弾を Claude が出す）。口をあけた笑顔
3. **P06 チャージ／詠唱**：両手を胸の前で向かい合わせ、手のひらの間に空間をあける（ここにゲルが集まる演出を Claude が重ねる）。目を細めて集中
4. **P07 必殺技**：P06 とは別の強い決めポーズ。両腕を右上へ大きく突き出し、髪と袖布が大きく後ろへなびく。足を大きく開いて踏んばる

## 3段目｜支援・やられのポーズ（左から）
1. **P08 支援／回復**：片手を胸に当て、もう片方の手のひらを上に向けて右前へ差し出す。やさしい表情
2. **P10 被ダメージ**：右から攻撃を受けて、上半身が後ろ（左）へのけぞる。片手で顔の前をかばう。驚きと痛みの表情（傷は描かない）
3. **P11 戦闘不能**：右向きのまま片ひざをついてしゃがみこみ、うつむく。片手を床につく。体は溶けたり崩れたりしない
4. **P12 発動後の余韻**：技を撃ち終えて、右へ伸ばした腕をゆっくり下ろしかけたポーズ。余裕の微笑み

## 4段目｜個性のポーズ（左から）
1. **P13 挑発／アピール**：右の敵に向けて、人差し指で「おいで」をする。いたずらっぽい笑顔とウインク
2. **P14 セクシーポーズ（勝利と兼用）**：正面〜少し右向き。片手を頭の後ろ、片手を腰に当てた上品な決めポーズ、ウインク。ガチャや図鑑にも使う。性的なポーズにはしない
3. **SP01 固有技・伸縮**：右腕がゲル状に長く伸びて、右の敵へ届くように伸ばす（腕の形のまま伸び、手は指先まで描く）。体は床に踏んばる
4. **SP02 固有技・分裂と拘束**：両手を前に広げ、指先から細いゲルの帯が数本のびて右へ向かう（帯は指から続く形。空中に浮かぶしずくは描かない）。不敵な笑み
